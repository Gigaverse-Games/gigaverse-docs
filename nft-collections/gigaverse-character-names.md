# Gigaverse Character Names

Gigaverse has a unique character name system wherein each name is minted as a tradable NFT.

Players can mint one new name when creating a new account.&#x20;

These Name NFTs can be transferred to existing accounts allowing players to change their display name in-game.

### Marketplace: [OpenSea](https://opensea.io/collection/gigaverse-names) (Abstract)
