# Abstract XP

<figure><img src="https://dalaoge.gitbook.io/gigaversecn/~gitbook/image?url=https%3A%2F%2F2356007408-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Ficab3JzUz7MddSO6Rfl1%252Fuploads%252FXoCrNlQmW68xC3IVOXRX%252Fimage.png%3Falt%3Dmedia%26token%3Da28e7b39-00d0-4e8a-a0c7-51815613a575&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=a53554aa&#x26;sv=2" alt=""><figcaption><p>Abstract Chain</p></figcaption></figure>

Abstract XP 是由 Abstract 提供的激励与参与系统，Gigaverse 部署在 [Abstract ](http://abs.xyz/)公链上。

在 Abstract 上，XP 可以通过多种方式获得，例如使用各种 APP、交易、铸造、持有（NFT、ERC20 代币）等等。

具体机制官方尚未对外公开，基于权重的分配会每周动态调整。

在 Gigaverse 中，获得 Abstract XP 的方式主要有两种：

* 主动获取：通过玩游戏、收集道具并将它们卖给木桥上的旅行商人（直接点击左侧菜单栏 Vendor 按钮）来兑换 Abstract Stubs
* 被动获取：持有 [Gigaverse ROMs](https://dalaoge.gitbook.io/gigaversecn/nft-collections/gigaverse-roms)

{% hint style="success" %}
重要提醒：快照将在每周五 UTC 时间中午 12:00 进行。Abstract Stubs 会在快照时被销毁并自动计入 Abstract XP（无需手动操作）。
{% endhint %}

{% hint style="danger" %}
Abstract Stubs 不会结转到下一周。
{% endhint %}

{% hint style="danger" %}
Abstract Stubs 与 Abstract Portal XP 并非 1 : 1。
{% endhint %}
