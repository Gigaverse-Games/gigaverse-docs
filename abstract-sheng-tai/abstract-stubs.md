# Abstract Stubs

## Abstract Stubs

Abstract Stubs 是用于计算你每周能赚取多少 Abstract XP 的积分系统。

{% hint style="success" %}
简单来说：Abstract Stubs 越多 = Abstract Portal XP 越多
{% endhint %}

玩家可以通过以下方式赚取 Stubs：

* 与木桥上的[旅行商人](https://dalaoge.gitbook.io/gigaversecn/lore-and-special-characters/hugis)进行物品交易（出售指定物品）；分为两种类型 —— 左侧的每周更新和右侧的每日更新
* 持有 [Gigaverse ROMs](https://dalaoge.gitbook.io/gigaversecn/nft-collections/gigaverse-roms)
*   购买 [Giga Juice](https://dalaoge.gitbook.io/gigaversecn/giga-juice)（仅限自动售货机明确标注有奖励时）

    <div data-gb-custom-block data-tag="hint" data-style="warning" class="hint hint-warning"><p>更多赚取方式即将上线，敬请期待</p></div>

    \*\*\*

#### 旅行商人 [Hugis & Munis](https://dalaoge.gitbook.io/gigaversecn/lore-and-special-characters/hugis)

这两位商人提供每日与每周交易，你可以通过出售特定的物品来获得 Abstract Stubs。

注意：出售物品的数量存在上限。

#### [Gigaverse ROMs](https://dalaoge.gitbook.io/gigaversecn/nft-collections/gigaverse-roms)

持有者会被动获得 Stubs。

Stubs 会自动被领取，玩家无需手动操作。

ROM 可以从 1 级升级至最高 60 级，等级越高，被动产出的 Stubs 数量越多。了解更多：[Gigaverse ROMs](https://dalaoge.gitbook.io/gigaversecn/nft-collections/gigaverse-roms)

{% hint style="warning" %}
必须在每周快照时（每周五 UTC 时间中午 12:00）持有 Gigaverse ROM 才能获得。
{% endhint %}

#### Giga Juice [如何开通Juice？](https://dalaoge.gitbook.io/gigaversecn/giga-juice/how-to-buy-giga-juice)

对于想要最大化每周 Abstract Stubs 收益的玩家，Giga Juice 提供强力增益：

1. 向旅行商人出售物品时所得的 Stubs 会变成原本（没有开Juice的情况）的四倍
2. 作为购买 Giga Juice 的额外奖励，有些时候会额外发放 Stubs（并非总是可用）
