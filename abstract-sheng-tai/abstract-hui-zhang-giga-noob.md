#### 操作步骤 ⬇️

**步骤 1**：访问 [https://gigaverse.io/](https://gigaverse.io/)，点击 {Connect} 按钮，并使用 Abstract Global Wallet (AGW) 登录。

**步骤 2**：输入用户名并点击 {Claim Noob 0.005 ETH}。

{% hint style="info" %}
你的钱包中必须有 0.005 ETH 才能铸造 Noob 并进入游戏。如果需要将资金桥接到你的 Abstract 钱包，可以使用 [Abstract Portal](https://portal.abs.xyz/profile) 。
{% endhint %}

**步骤 3**：前往 Abstract 的 rewards 页面领取徽章。

{% hint style="success" %}
就是这么简单！在购买完成不久之后你将在 Abstract 上获得 Giga Chad 徽章。
{% endhint %}
