# 关于Gigaverse

Gigaverse 是一款史诗级链上角色扮演游戏，由 GLHF 工作室打造，现已在 Abstract 平台上线，底层技术由 Proof of Play 提供支持。在这片元宇宙中，您可以按照自己的游玩方式推进游戏进程以赢取奖励，升级角色属性，收集稀有道具，并解锁更多精彩玩法。尽情畅玩，书写属于您的链上冒险传奇！

Gigaverse 并没有固定的官方路线图：游戏及生态系统的更新会以滚动、不定期的方式推出，以此来为玩家和社区带来各种意想不到的惊喜。这种模式让开发团队能够保持高度的灵活性，且会始终围绕玩家的真实需求来进行构建与交付。

Gigaverse的核心游戏设计理念包括：

1. **简单易懂，轻松上手 ——** 我们希望无论是你的舅舅 Jebediah，还是你的小侄女 Zelda，都能乐在其中。
2. **冒险与回报并存** —— 通过精心设计的玩法，让玩家既能感受到冒险带来的刺激（祝你好运），也能在收获奖励时尽情享受成就感（玩得开心）。
3. **怀旧与沉浸感结合** —— 通过高品质的像素艺术与经典 RPG 剧情设定，带来跨越时代的怀旧体验，而你将是这段史诗故事的核心主角。

我们期待你的加入，欢迎踏入 Gigaverse 的世界。
