# 工作台

#### 位置

工作台位于地下城的入口附近。

#### 功能

制作装备。装备在 Gigaverse 中非常有用，能够为玩家提供属性加成或者一些被动技能等等。

#### 材料需求

制作每件装备所需的材料各不相同。

#### 阵营特定材料需求

制作大多数装备不需要特定派系的材料。如果需要，会在所需材料中注明。

#### 成功率

当前制作装备的成功率为 100%。未来的更新可能会加入一些非 100% 制作成功率的装备。
