#### 位置

炼金工作台位于地下城入口附近。

#### 功能

制作消耗品以供在地下城中使用。

#### 资源需求

制作每种消耗品所需的材料各不相同。将鼠标悬停在某个消耗品上即可查看其所需材料。较高阶的消耗品需要更多的材料来制作。

#### 派系特定资源需求

制作消耗品需要特定派系的材料。例如，制作 boom juices 需要某一派系类型的 Dust 或 Shard，而制作 armor juices 则需要另一派系类型的 Dust 或 Shard。

#### 成功率

制作消耗品的成功率为 70%。也就是说，玩家会有 70% 的几率成功制作出消耗品，也有 30% 的几率制作失败并损失材料。
