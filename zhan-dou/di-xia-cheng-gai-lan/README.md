# 地下城概览

## 地下城概览

Dungetron 是一种类 Roguelite 地下城，敌人难度会随着关卡逐步增加。地下城一共有 4 层，每一层包含 4 个房间。玩家在击败房间内的敌人后可以获得其掉落的道具，这些道具即使在玩家死亡后也会保留。不过在玩家死亡后，地下城关卡进度将被重置（自动返回地下城入口），必须重新开始挑战。
